# InternConnect - Local Internship Portal

A beginner-friendly internship portal built only with:

- HTML5
- CSS3
- Bootstrap 5
- JavaScript
- Python
- Flask
- MySQL through XAMPP

# Main users

# Student
- Register and login
- Complete profile
- Upload resume
- Search internships
- View internship details
- Apply with cover letter
- Track application status

# Company
- Register and login
- Create company profile
- Post internships
- View applications
- Review, shortlist, accept or reject students

# Setup

1. Install Python.
2. Install XAMPP.
3. Start MySQL from XAMPP.
4. Open phpMyAdmin.
5. Import `database/schema.sql`.
6. Open terminal in this project folder.
7. Run:

```bash
pip install -r requirements.txt
python app.py
```

8. Open:

http://127.0.0.1:5000

# Database

The database name is:

`internconnect`

Default XAMPP configuration used by this project:

- Host: localhost
- User: root
- Password: empty

If your XAMPP MySQL password is different, update `app.py`.
